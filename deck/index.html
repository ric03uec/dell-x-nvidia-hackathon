ALWAYS-ON DETECTION / 06

Two detection speeds catch both obvious spikes and slow cross-action attacks.

<1sLIVE PATH

Immediate anomaly scoring

Rules, rolling baselines, and CPU Isolation Forest score each new event without depending on an LLM.

HISTORYOFFLINE PATH

Sequence-level analysis

A safe SQLite snapshot and GPU PyTorch model find slow, related patterns across longer windows.

DETERMINISTIC EVIDENCE→ALWAYS-ON SECURITY AGENT
Fast and deep analysis have different jobs. The live path catches immediate anomalies in seconds. The offline path uses GPU and historical windows for slower patterns. Both produce deterministic evidence before the security agent adds explanation.

Autonomous defense cannot mean autonomous privilege escalation. The model only recommends an allowlisted action. A human approves it. The adapter validates it again before OpenShell applies it, and the result becomes an audit event.
